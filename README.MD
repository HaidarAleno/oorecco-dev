# Run Locally
To run this project locally, you can download it as a ZIP file (the easy option).

Alternatively, if you prefer using the Command Line Interface (Which probably you are a Linux user without a desktop environment, and only use TUI for some reason), open an empty folder and run the following command: 
```bash
git clone https://github.com/Oorecco/oorecco.github.io.git
```
Either way, open the folder using your preferred code editor. If you need a recommendation, [Visual Studio Code](https://code.visualstudio.com/download) is a great option for running a local server, but the choice is entirely yours.
